# Что нужно от команды ML/разметки (одной страницей)

Нужен **один файл** с результатом разметки:

```
data/labeled_routes.jsonl
```

По одной JSON-записи на строку. Как вы получили результат (правила, LLM, ручная разметка) —
не важно, важно совпадение полей.

- Полное описание: `docs/api_contract.md`
- Машиночитаемая схема: `schemas/labeled_record.schema.json`
- Пример на реальных данных: `data/labeled_routes.sample.jsonl`
- Проверка формата: `python scripts/validate_labels.py data/labeled_routes.jsonl`

## Формат записи

```json
{
  "protocol_id": "протоколы Ж ОМТ/1 Ж ОМТ (21).docx",
  "patient": { "id": "П-5840", "age": 53, "sex": "Ж" },
  "study": { "type": "УЗИ органов малого таза", "date": "2026-08-13T10:00:00" },
  "findings": [
    {
      "id": "endometrial_polyp",
      "title": "Полип эндометрия",
      "domain": "Гинекология",
      "status": "trigger",
      "severity": "planned",
      "confidence": 0.9,
      "evidence": "…цитата из протокола…",
      "match": "полип эндометрия",
      "attributes": { "size": "12х11мм" },
      "rule_version": "0.1"
    }
  ],
  "routes": [
    {
      "finding_id": "endometrial_polyp",
      "specialist": "Оперирующий гинеколог",
      "next_step": "Консультация оперирующего гинеколога",
      "planned_step": "Гистероскопия / гистерорезектоскопия",
      "target_days": 7,
      "priority": "planned",
      "priority_reason": "Хирургически значимая находка, плановая операция"
    }
  ]
}
```

## Главное (жёсткие требования)

1. **`status`** — три значения:
   - `trigger` — находка подтверждена → создаётся маршрут;
   - `uncertain` — реально противоречивая формулировка («нельзя исключить») → маршрут **не создаётся**,
     попадает в очередь «Требует уточнения»; при этом указывается `marker` с этой формулировкой;
   - `negated` — находка отрицается («не выявлено») → маршрута нет.
2. **`evidence`** — обязательная цитата из текста. Без неё нет объяснимости.
3. **`routes`** — это **список**: по одному маршруту на каждую находку `trigger`.
   Если находок несколько — маршрутов несколько (не теряйте их).
4. **`priority`** — `emergency` / `urgent` / `planned` / `watch`. Задаётся **правилами**, не LLM.
5. **Только обезличенные данные** — никаких ФИО, телефонов, СНИЛС.
6. **`protocol_id` стабилен** при повторной выдаче/исправлении — иначе будут дубли маршрутов.

## Список синонимов неопределённости

Маркеры вроде «нельзя исключить», «под вопросом», «заподозрить», «требует уточнения» собраны
в файле `rules/uncertainty.json`. Врачи пишут по-разному — список ведёт медэксперт и пополняет
без изменения кода. Если увидите новую формулировку — сообщите, добавим.

## Проверка у себя

```powershell
python scripts/validate_labels.py data/labeled_routes.jsonl
```
Скрипт не требует сторонних библиотек. Ненулевой код возврата = формат не соответствует контракту.

## Что делает интерфейс (не дублируйте)

Читает ваш файл, строит очередь координатора, сортирует по `priority`, считает просрочку,
сам формирует **нейтральное** уведомление пациенту (без диагноза), ведёт журнал и очередь
«Требует уточнения». Вам не нужно делать: фронтенд, тексты уведомлений, эскалации, дашборд.
